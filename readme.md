## 🎆 **Meet M.A.R.K.**

**M.A.R.K. (Machine Augmented Reality Kernel)** is an advanced, voice-controlled AI system designed specifically for **macOS**. It acts as your personal Jarvis, capable of controlling your entire computer, searching the web, and holding intelligent conversations through a stunning, audio-reactive visual interface.

> 🎤 *"MARK, open Safari and search for the latest AI news."* → **Done instantly!**

---

## 🌟 **Features**

<table>
<tr>
<td width="50%">

### 🎤 **Voice & Interaction**

🎙️ **Always-On Wake Word**
- Just say **"MARK"** to activate hands-free
- Fuzzy matching detects "Mark", "Marc", or "Park"
- **Anti-feedback system** prevents self-triggering

✨ **Premium Orb Interface**
- **3D Particles:** 40 orbiting light embers
- **Audio-Reactive:** Pulses to AI's voice
- **Dynamic States:** Dormant, Listening, Thinking, Speaking
- **Retina-Ready:** Crisp canvas rendering

🔊 **Natural TTS**
- Uses high-quality Edge TTS voices
- Fluid, conversational responses

</td>
<td width="50%">

### 💻 **System Control (macOS)**

📂 **File & App Management**
- Open any App (Spotlight intergation)
- Create/Open Files & Folders
- Search laptop for documents

⚙️ **Hardware Control**
- **Brightness:** "Set brightness to 50%"
- **Volume:** "Mute", "Volume up", "Set to 80%"
- **Window Management:** List & Focus windows
- **Power:** Sleep, Restart, Shutdown

🌐 **Web Intelligence**
- **Real-time Web Search** (SerpAPI)
- **WhatsApp Integration** (Send messages)
- **Media Control:** Play Music (Spotify/YouTube)

## 🛠️ **Installation**

<details open>
<summary><b>🚀 Quick Setup</b></summary>

<br>

**Prerequisites:**
- ✅ macOS (Ventura or later recommended)
- ✅ Python 3.10+
- ✅ Microphone access enabled
- ✅ `brew install brightness` (optional, for native brightness control)

**Step-by-Step:**

```bash
# 1️⃣ Clone the repository
git clone https://github.com/Daivik1520/MARK.git
cd MARK

# 2️⃣ Install dependencies
pip install -r requirements.txt

# 3️⃣ Verify .env configuration
# Ensure OPENROUTER_API_KEY and SERPAPI_KEY are set

# 4️⃣ Run M.A.R.K.
python app.py

# 🎉 M.A.R.K. is live at http://localhost:5001
```

</details>
